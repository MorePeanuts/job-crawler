# SPEC-017 第二批前程无忧定制活动页

状态：开发中。2026-10-12。

## 目标与非目标

接入名录中的蓝思科技 COM0245、中国燃气 COM0259、天津银行 COM0406。三站均为前程无忧定制活动页，分别按已观察的页面内岗位数组或静态卡片采集，不把域名相同视为结构相同。本批不接入只有标题而无岗位正文的李宁页、占位页、历史失效页，也不自动投递或登录。

## 输入、范围与输出

- 蓝思：`/lens/about1.html` 的页面内 `obj` 全量数组；校验数组与页面岗位展示来源一致，逐项使用 `attr5` 的 `jobid` 作为唯一键，读取岗位职责、要求、工作地点和单位/类别。公开探测时有 26 项；运行时以当次数组长度为准。
- 中国燃气：名录入口 `/chinagasholdings/page1.html` 导航到唯一「校园招聘」页 `/page2.html`；页面 `jobListData` 是无筛选目录，页面按该数组渲染 `.list`。核对数组 ID 与完整 DOM 卡片 ID，逐项读取 `jobinfo`、`jobarea` 和申请 ID。公开探测时有 308 项；运行时以当次数组长度为准。
- 天津银行：名录 `/tjyh_2026/contact.html` 的「热招岗位」与「专项招聘」两个公开分支，分别为 `/job.html`、`/jobs.html`。热招页包含两个直接申请岗位和一个按 19 个城市分别提供申请 ID 的岗位；专项页按 7 个城市提供申请 ID。每个城市申请 ID 是独立记录，不能只抓当前激活城市。公开探测时共 28 个申请 ID；运行时以页面实际链接和城市数为准。
- 所有记录进入现有 `Job`、覆盖核验、窗口筛选与十三列交付流程。没有公开发布时间/截止日就留空，不从 2025/2026 活动页名称推断日期。登录申请页仅作为投递链接，不触发投递。

## 失败行为

入口、页面数组、导航目标、卡片数、申请 ID、岗位正文或唯一键无法核验时，将受影响来源标记 partial/blocked 并保留已采记录；任一分支失败不能因另一个分支成功而标 complete。来源重新设计、岗位总数变化、重复 ID 或页面只显示占位内容均需要重新验收，不把零记录视为成功。对中国燃气年份较早的活动页，不声称源站已确认岗位仍开放；只报告其仍公开展示且无可解析截止日期。

2. 三来源实际使用 Crawl4AI 全量采集，报告包含当次目录数量、各分支覆盖、详情字段、错误、证据与运行时刻；只有 complete 才加入 `sites/bindings.toml`。
