# SPEC-031 上海建工校招活动页

## 目标

接入 COM0136 上海建工活动页公开“校园招聘”目录。该页的前程无忧 COAPI 先读取无筛选职位列表，再只显示标题含“应届”的岗位；适配器按同样可见规则核对页面卡片并逐条采集详情。

## 非目标

页面“社会招聘”、登录投递、标题不含“应届”的列表行。

## 输入输出

输入为来源和采集配置，输出为岗位快照、覆盖报告和导入候选 Excel；无明确截止日期留空。

## 失败行为

总数超出单次返回上限、页面卡片与过滤后的 ID 不一致、详情租户或 ID 不一致时 partial，保留证据。

## 验收

- `ctmid=4963893` 且 COAPI 无筛选目录完整返回。
- 标题含“应届”的 ID 与页面可见卡片集合一致，详情 ID 逐条匹配。
- 真实运行 complete 及离线回归通过后绑定。
