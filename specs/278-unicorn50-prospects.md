# SPEC-278 当日 50 家目标补充候选：芯驰、波克、转转、燧原、认养一头牛、星星充电

状态：2026-10-22 真实全量验收通过；纳入 SPEC-277 最终 50 家审计。

## 目标与非目标

从 SPEC-277 批次开始时未绑定的 `sites/sources.csv` 企业中接入仍展示、未截止的正式校招岗位。先验证 COM0630 芯驰科技、COM0622 波克、COM0585 转转、COM0598 燧原科技、COM0682 认养一头牛和 COM0603 星星充电；只有公开目录完整、主体可证、有效岗位大于零时才计入累计 50 家。不采集社招、实习、不以平台首页热招卡片代替完整岗位目录，也不把学校转载页作为岗位来源。

- COM0630 官网 `www.semidrive.com/aboutus/` 的“加入我们”进入 Moka 社招站 `semidrive/42940`；该站“校园招聘”直链同租户校招站 `semidrive/42941`。首页“校招岗位”模块请求 `jobs/module`，`orgId=semidrive,siteId=42941,moduleId=0001295480,commitments=[全职],needGroupType=list`，当前可见 7 岗；实习是独立模块。须核对模块全部页、详情 ID、正文和正式性质，不把社招站或实习模块混入。
- COM0622 官网 `www.boke.com/join.html` 的“校园招聘”直链 `boke.jobs.feishu.cn/581609`。职位列表 `/581609/position/list` 的公开飞书请求 `portal_type=6,offset=0,limit=10` 无类别、地点、项目筛选，页面当前显示 111 岗；以源总数和末页核对每个 ID，源性质和项目决定正式/实习。

- COM0598 `app.mokahr.com/campus-recruitment/enflame/168420#/jobs/` 公开目录当前 48 岗，列表显示“上海燧原科技股份有限公司”和 2027 校招标题，Moka `orgId=enflame,siteId=168420,site=campus`；须补核企业官方入口，按源公司部门和性质逐条验证，不把旧官网 404 或转载网申地址当作官方直链证明。

输入为上述公开入口的浏览器渲染、列表与详情响应；输出为版本化适配器、正式绑定、逐站快照、审计以及更新后的当日累计岗位信息表、严格导入表和待补全报告。发布时间只用源 `PostDate` / `publishedAt` / `publish_time`，未提供则空；不将抓取时间或更新日代入。

## 失败行为与验收

页面拦截、平台接口变更、主体不明、总数变动、分页提前为空、详情错配、岗位仅实习或社招，均留存证据与错误，不启用正式绑定、不计入有岗位企业。学历、地点、地址、分类或发布日期缺失时保持空值并进入待补全；已成功岗位继续保留，coverage 标为 partial。

每站必须有首/末页、总数、唯一 ID、岗位正文及真实运行报告，且 `coverage=complete`、正式有效岗位大于零。测试应覆盖模块筛选和全职性质、飞书分页签名与末页、北森校园类型及详情身份、Moka 列表与详情关联；发布后按 SPEC-277 的批次基线与审计重算累计企业数和岗位数。不得把开发中目标标记为已实现。
