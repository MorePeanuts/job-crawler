# SPEC-246 中国科大三家认证企业账号的 2027 届岗位

状态：已实现并于 2026-10-20 真实验收；属于 SPEC-238 新增 50 家批次。

## 目标与非目标

复用 SPEC-245 已验证的中国科学技术大学就业信息网 `companyinfo` 与 `jobinfo` 协议，采集三家名录主体在各自认证账号当前公开的 2027 届全职岗位：铜陵有色金属集团控股有限公司（账号 5563）、中伟新材料股份有限公司（账号 165411）、山鹰国际控股股份公司（账号 530）。只代表各高校账号展示范围，不推断企业全网岗位；不采集历史届别或非全职岗位，不自动投递。

## 输入输出

- 各账号主页 `Jobinformation/info.aspx?itemid=<账号>` 的 `companyinfo` 必须与名录完整名称及统一社会信用代码相符，且返回非空唯一 `JobList`。三家代码分别是 `91340700151105774A`、`91520690314383681D`、`91340500150523317H`。
- 对主页列出的每条岗位读取 `jobinfo`，核对岗位 ID、标题、企业账号、企业名称、全职性质和列表/详情发布日期。铜陵仅纳入标题含“2027年校园招聘”且要求明确“2027届”的岗位；中伟仅纳入标题以“2027届”开头的岗位；山鹰仅纳入要求明确“2027届毕业生”的岗位。其他列表项计入范围排除而非悄然忽略。
- 保留详情职责、要求、学历、工作地点与页面标注的发布日期。页面招聘期限为空时截止日期留空；岗位人数不复制成多行。模板字段不足进入信息表及待补全表。

## 失败行为与验收

主体或代码不匹配、目录空、岗位 ID 重复、详情关联不一致、字段变化时覆盖失败；逐岗错误保留已成功岗位并报告 partial。离线回放覆盖三种届别条件、跨主体详情、重复和范围排除。真实采集须核对当前账号全部列表行、源报告、岗位详情与单源审计；通过后正式绑定并纳入批次合表。

本轮铜陵有色、中伟新材料、山鹰国际分别采得 1、4、2 条，三家 coverage complete 且单源只读审计通过；各条进入信息和待补全表，严格导入 0。11 家合表只读审计亦通过。
