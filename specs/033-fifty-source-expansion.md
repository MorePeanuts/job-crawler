# SPEC-033 再接入五十家企业招聘来源

状态：进行中；本轮已完整验收 8/50 个来源并生成程序汇总，尚未满足五十家全覆盖目标。

截至 2026-10-13，已完整验收来源为 COM0026、COM0128、COM0144、COM0178、COM0180、COM0210、COM0326、COM0449；实采记录共 2,268 条，其中 COM0128 明确返回零岗位。验收详情、另外 42 个未完成来源及障碍见 [第四批验收记录](../docs/adapter-batch4-acceptance.md)。该状态是阶段结果，不代表 SPEC-033 已完成。

## 目标

从最新版来源清单中选出 50 家尚未接入的企业，优先复用已实现的招聘平台适配器，同时为必要的新协议开发独立适配器；逐一验证入口范围、分页/分支终止、岗位详情关联和企业归属，采集本轮公开展示且仍有效的全部校招岗位，并通过程序生成一份汇总 Excel。

## 非目标

不绕过登录、验证码、403 或站点访问限制；不把历史招聘批次、实习、社会招聘或其他法人岗位混入目标；不手工补录岗位，不将局部结果或零结果说成完整采集。

## 输入与范围

输入为 `sites/sources.csv` 中以下 50 个当前未绑定的来源 ID：

`COM0004, COM0005, COM0011, COM0025, COM0026, COM0031, COM0034, COM0039, COM0118, COM0128, COM0133, COM0144, COM0166, COM0178, COM0180, COM0183, COM0192, COM0203, COM0210, COM0216, COM0217, COM0220, COM0232, COM0234, COM0238, COM0261, COM0274, COM0308, COM0313, COM0326, COM0337, COM0342, COM0346, COM0352, COM0360, COM0362, COM0367, COM0378, COM0379, COM0381, COM0385, COM0402, COM0448, COM0449, COM0453, COM0454, COM0482, COM0485, COM0493, COM0500`。

`COM0203` 中国铁塔官方 2027 校招公告需证明公告中的各岗位分支和岗位明细已穷尽后，才可计入完整采集；若仅提供申请链接且无岗位目录，保持 pending。

支持的平台候选包括北森、前程无忧活动页、智联招聘、Hotjob、飞书招聘、Moka 与 TCL 集团入口；相同平台需按租户/活动分别确认目录及法人范围。新网站必须先形成可核对的 Crawl4AI 页面或网络证据，再实现适配逻辑。

## 输出

- 版本化适配器、逐来源 ready/pending 状态和脱敏回放测试。
- 每个被接入来源本轮独立的原始快照、采集报告和完整性证据。
- 一份由 `job-crawler bundle` 从本轮采集快照生成的 13 列 `岗位信息汇总.xlsx`，另含企业采集情况；严格导入表与待补全报告留在同一输出目录。
- 验收记录说明 50 家目标中实际完整接入家数、岗位数、过滤数、字段待补全数及所有阻塞来源。不得以“尝试 50 家”替代完成情况。

## 失败行为

目录/详情数不匹配、重复页、总数变化、历史活动页、无可靠终止标志、跨法人范围不清或明示访问限制时，保留已采集证据并将该来源标记为 partial/blocked/pending。零岗位只有在校招目录明确返回总数为 0、列表为空且有有效结束状态时才可验收为 complete。切换到候选池中的其他来源前须更新本 spec 的 ID 清单与调研依据。源站无可靠发布时间或截止时间时留空，不用采集时刻代替。

## 验收

1. 每个 ready 来源都有匹配的 URL、租户、岗位范围和适配器版本；每个目录/单位/批次有终止依据；unique 列表 ID 与详情或经证明可复用的详情数相符。
2. 每个 ready 来源当日真实运行 `coverage=complete`，岗位按本轮公开在招状态过滤；全量运行报告保留部分失败和排除理由。
3. 最终 Excel 每个岗位只由程序生成，岗位明细与企业采集情况页的公司和岗位计数一致，13 列和日期格式符合模板。
4. 执行 `uv sync --locked`、Ruff 格式与检查、`ty check`、`pytest`；真实站点验收和离线测试分开记录。
5. 在功能分支分阶段提交并推送，创建 PR；不合并 `main`。
