# SPEC-067 中天科技集团 2027 届校招活动页

状态：已实现并真实验收。日期：2026-10-14。归属 SPEC-050。

## 目标与非目标

接入 COM0192 中天科技集团有限公司官方招聘活动页 `https://campus.51job.com/ztt/positions.html`。页面明确面向 2027 届，静态 `.job-list > .job-item` 有八个可投递岗位类别，每项有独立 51job 岗位 ID、申请入口、应聘条件、需求专业和工作地点。逐卡采集，不拆造专业或城市为额外岗位。

不把仅在宣传页出现的职位名称、城市或宣讲活动视为额外岗位。源未提供每项职责、发布日期或截止日，保留缺失，不猜填。

## 输入输出与失败行为

输入为上述公开职位页；输出为与八个独立申请 ID 一一对应的证据化岗位记录，由公共流程筛选和生成十三列表格。检查站点导航、非空卡片、每卡唯一 HTTPS 51job 申请 ID、2027 应届条件及三个字段标签。卡片缺失、重复 ID、跨站跳转或应届条件变化时 coverage 非 complete，保留已读记录及问题。

## 可验证验收条件

1. 离线回放证明八卡结构、唯一 ID、标签提取、空卡/坏链接/重复 ID 失败。
2. 真实采集 `expected=listed=unique=details`，`coverage=complete`，至少一条有效正式校招；缺失字段透明列在待补全报告。
3. 完成后更新正式绑定，纳入 SPEC-050 的离线汇总及归档。
