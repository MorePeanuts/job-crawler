# SPEC-245 楚江新材中国科大校园岗位

状态：已实现并于 2026-10-20 真实验收；属于 SPEC-238 新增 50 家批次。

## 目标与非目标

采集中国科学技术大学就业信息网中安徽楚江科技新材料股份有限公司认证企业主页当前公开的全部岗位。企业主页公开公司全称、统一社会信用代码和 `JobList`，本轮有七条全职岗位；主页说明这批岗位均为“总裁直培生”。范围限该高校账号，不代表公司其他招聘渠道或历史岗位；不执行简历投递。

## 输入输出

- 入口为 `https://www.job.ustc.edu.cn/Jobinformation/info.aspx?itemid=26568`。依据浏览器观察到的 `Ajax/jywapi.ashx` 请求读取 `action=companyinfo,cid=26568`；校验完整公司名、统一社会信用代码 `91340200743082289Q`、主页公开的培养批次说明，以及非空且唯一的 `JobList` ID。该主页没有分页，逐条遍历 `JobList` 才可声明该账号范围完整。
- 对每个 ID 读取同站 `action=jobinfo,jid=<ID>`，确认 `CompanyID=26568`、岗位 ID 和标题与列表一致，且工作性质为全职；保留详情原文的职责、要求、学历、地点及页面标注的发布日期。人数只是招聘数量，不复制行。页面无截止日期时留空，不用抓取时间补日期。
- 输出符合现有岗位模型的公司名及岗位证据；模板缺失的字段继续进入信息表和待补全表，只有满足导入约束的岗位进入严格导入表。

## 失败行为与验收

主体、代码、岗位批次、列表/详情身份或目录结构变化时报告覆盖失败；逐岗详情错误保留其他成功记录并报告局部失败，不把空目录算成功。离线回放验证七岗遍历、身份校验、重复 ID 及局部失败。真实网站按当前主页七条与逐条详情核对，通过单源只读审计和批次合表审计后才正式绑定、计入一家。

本轮企业主页 7 条、逐条详情 7 条，selected/information/review 各 7，严格导入 0；单源及 11 家合表只读审计均通过。
