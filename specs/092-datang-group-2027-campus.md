# SPEC-092 大唐集团 2027 校招分公司范围

状态：已实现并实采验收。日期：2026-10-14。归属 SPEC-050。

## 目标与非目标

接入 COM0111 中国大唐集团有限公司的公开 2027 校招公告目录 `https://zhaopin.china-cdt.com/zpgg_xyzp.html?random=1790467200101`。仅纳入公告与逐岗单位证明属于集团法人或其未独立设立法人的分公司、内部事业部的正式岗位。独立子公司、公告标题虽为分公司但逐岗备注指向独立公司、以及集团集中招聘但用工单位未确定的管培项目均排除。不登录、申请或投递。

## 输入输出与失败行为

读取页面观察到的无关键词 `xyzpHomeInfo`，其 `total` 与 `list` 公告数闭合、公告 ID 唯一。对于组织名为集团本身或以“中国大唐集团有限公司”开头的分公司公告，逐一按公告 ID 请求 `findInfo`，验证返回的公告 ID；其嵌套 `details[].applyId` 可为下属岗位公告 ID，不强制等于父公告 ID，但必须非空，并逐条检查唯一 `bringId`、`organName`、`ownOrganName` 和 `remark`。集团管培项目跨二级单位、跨省分配，主体无法逐岗确定，本版不纳入。重庆分公司本级、宁夏与辽宁分公司内部新能源事业部可纳入；详情指向带“有限公司”“股份有限公司”的独立主体排除。不得只按公告署名将子公司的岗位归入集团。

每条岗位以 `bringId` 为来源键；`post` 是岗位名，`specialName` 为招聘专业，`postDuty`、`postDemand` 为逐岗职责和要求。`applyPublicTime` 是公告公开时间，`usefulLifeEnd` 和公告 `endDate` 为截止时间，地点保留 `workPlace` 原文；未知学历、地址、分类不补造。逐公告建立岗位 scope，公告目录单独建立公告 scope。目录数量、请求或单位身份变化、ID 重复、详情缺字段和日期错误导致局部失败，保留已成功岗位，覆盖不得标完整。

## 可验证验收条件

1. 离线回放核验公告数量、11 个集团及分公司候选公告的单位边界、同名不同专业岗位 ID、子公司备注和详情局部失败。
2. 当日独立状态库 `--window all` 真实读取完整公告目录与全部候选详情；按 scope 闭合后 `coverage=complete` 且有效岗位大于零。
3. 真实验收后才更新来源和绑定，纳入本批新增集合审计、汇总发布、归档；通过 Ruff、ty、pytest。
