# SPEC-075 民生银行公开校招目录

状态：已实现并真实验收。日期：2026-10-14。归属 SPEC-050。

## 目标与非目标

接入 COM0108 中国民生银行股份有限公司公开招聘门户的 `campus` 目录。机构树与无机构筛选的岗位列表均报告 113 条；机构树中的银行总行及各分行为本主体，民生金融租赁、民生加银基金、民生科技、民生理财、民生置业的 23 条岗位排除。仅采集仍展示且未截止的正式校招岗位，不采集 `social` 与实习生目录，也不访问投递或登录接口。

## 输入、输出和失败行为

入口为 `https://career.cmbc.com.cn/#/app/recruitmentlist/campus/`。读取 `enterpriseList.view?recruitmentId=campus` 的机构树，再对 `search.view` 发送已观察的 `view=careerRecruitmentList`、`searchRecruitmentIds=campus`、空 `searchEnterpriseId` 表单，按页号读取完整目录。岗位 ID 为唯一键，列表提供标题、机构、地点、逐岗位发布时间及截止日期。银行岗位读取公开 `view/{id}.view` 详情，核对 ID、标题、机构、地点、截止日期后分离职责和任职要求；详情页路由作为来源链接。

核对机构树总数与各机构数量之和、列表总数/页数/页码、每个机构的列表分布、唯一 ID 和末页数量。未知机构、总数变化、重复页、详情身份不符、正文缺失或请求失败时保留已采数据和证据，但 coverage 不得为 complete。只从列表发布时间填 `published`；不推断学历、类别或日期。未到截止日的岗位交由公共流程筛选与导出。

## 可验证验收条件

1. 离线回放覆盖多页、银行与五个子公司边界、重复页/机构分布变化、详情身份及局部失败。
2. 本日实采核对机构树与全目录 113 条、完整读取银行岗位详情并排除 23 条其他法人；达到 `coverage=complete` 且有效正式校招大于零。
3. 完整实采后启用正式来源绑定，纳入 SPEC-050 汇总并归档。
