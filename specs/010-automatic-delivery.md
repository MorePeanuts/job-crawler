# SPEC-010 默认采集自动完成岗位交付

状态：开发中。

## 目标与非目标

一次 `run` 完成采集、窗口筛选、规则规范化、缓存优先的 LLM 分类/学历辅助、模板校验和最终表格导出。用户无需另行运行 classify。保留独立分类工具和无需重爬的 export 重试入口。不新增自主导航、定时调度或虚构缺失数据，不改变十二列模板。

## 输入输出与行为

- 默认开启 LLM，使用已有 deepseek-flash/环境变量配置。可以显式关闭；关闭时仍导出已满足规则的记录，并报告缺失项。不是所有岗位都需要模型。
- 先筛选再调用模型；已过期、窗口外及日期待核验的岗位不消耗模型预算。先用明确映射和正文规则补字段，合法已有分类不重复推断。
- 批量分类与独立 classify 共用已验证缓存和复核流程。学历仅对规则无法确定的岗位请求模型，不改已确定的分类、地点、地址或日期。学历缓存绑定文本、模型/端点、提示版本和学历策略；命中也重新校验引证。
- 默认总预算 1000 次，涵盖分类、复核、学历及重试；分类批次 10、并发 5，可配置。缓存命中不消耗请求预算。报告分别记录调用量、缓存命中、未解决项，不把模型失败称为完成。
- 原始 collections/jobs.json 留存源数据；新增 delivered.json 保存入表及待补全的规范化结果，LLM 审计单独保存。最终表格直接在本轮输出根目录，用户不必寻找另一个分类目录。
- `export` 从已有快照完成同样的补全和导出，保留原窗口/时刻，不访问招聘网站；`bundle` 同样处理已保存结果。成功的缓存可用于下一次采集或失败重试。

## 失败行为

缺少密钥、预算耗尽、超时、非法路径、无效引证不能丢弃已采数据或阻止其他岗位导出。仍输出严格表、信息汇总表、待补全报告和模型统计，退出码 2；修复配置后可 export 重试。配置结构错误在采集前拒绝。不得为通过校验臆造字段。模型仅成功分类不代表其他必填字段均可导入。

## 验收

- 单条 run 编排在模拟浏览器/模型下生成分类完整的十二列表，不需要第二条 classify 命令。
- 第二轮相同内容命中分类/学历缓存，模型请求为零；内容、模型、策略变更和损坏缓存会失效。
- 窗口外/待核验岗位不送模型；已有合法分类保留；学历辅助不覆盖其他字段。
- 缺 key、调用预算、非法响应保留原始数据并输出 partial/report；可通过 export 在无浏览器情况下补齐。
- 既有分类命令、每日详情缓存、严格导入和全部回归测试保持通过。Ruff、ty、pytest 通过，README 给出单命令默认流程与重试说明。真实网站/模型验证与离线测试分开记录。
