# SPEC-146 中集集团 2027 校园招聘

## 目标

接入名录 COM0163 中国国际海运集装箱（集团）股份有限公司的官方 2027 届专题 `https://campus.51job.com/cimc/post.html`。完整采集无业务、类别、地点筛选的集团招聘目录和逐岗职责、任职要求。2026-10-15 探测时页面展示 18 页、公开 COAPI 返回 173 岗；集团专题包含各业务板块，不能仅采总部。

## 非目标

不采该平台其他租户、社招或实习；不把 API 的通用集团法人名称冒充每个岗位的具体用人单位。站点对部分岗位只显示简称时原样保留。

## 输入、输出与失败行为

输入为专题内 `ctmid=7973180` 的无筛选 `coapi.getJobList` 与以 jobid 关联的 `coapi.getJobDetail`。核对页面首屏、列表总数、唯一 ID、租户、全职性质及详情 ID，保存列表和详情证据。以页面业务编码与单位简称映射标记实际招聘单位，映射缺失时保留空值。输出源快照、信息表、严格导入表和待补全表。总数、页面、租户或详情契约异常时产生覆盖问题，不以部分成功冒充全量。

## 可验证验收

1. 离线回放验证目录总数、页面身份、业务范围、单位映射、详情关联与失败隔离。
2. 实站 `expected=listed=unique=details` 且 `coverage=complete`，正式校招岗位大于零。
3. Ruff、ty、pytest 全部通过，记录真实数量与导入字段限制。

对应测试：`tests/test_coapi51.py` 中集中集团租户回放。
