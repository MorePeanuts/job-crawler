# SPEC-013 Moka 公共校招站点

状态：十三个单站点租户已实现并真实验收，2026-10-12；多站点门户继续待适配。

## 目标与非目标

接入已经逐租户验证的 Moka `campus-recruitment/{orgId}/{siteId}` 或 `campus_apply/{orgId}/{siteId}` 公共单站点。读取无筛选的职位列表，按真实总数分页并关联公开详情。页面公开脚本以 AES-CBC 解读公共接口响应；适配器只复现这一公开数据格式，不登录、投递、规避验证码或假设所有 Moka 租户结构相同。移动入口须确认跳转后的规范 URL 与目录；跨多个 siteId 的导航门户另行调查，不自动合并为单一目录。

## 输入输出与范围

- 输入为清单中明确的组织 ID、站点 ID、路由族和 `#/jobs` 路由。验证本轮页面的 `window.TurboApply.data.aesIv` 是十六字节字符串，`website/jobs/v2` 的请求含对应租户、无职位/地点/职能筛选、`site=campus`、`offset=0`。只在移动链接公开跳转至相同组织及站点的桌面路由后复用桌面逻辑。
- 使用同一 Crawl4AI 浏览器会话请求 `jobs/v2` 与 `website/job`。解码只接受结构完整、`code=0`、租户及岗位 ID 一致的数据。`jobStats.total` 是目录数量，`limit/offset` 与唯一 ID 核对分页终点。
- 详情 `jobDescription` 保留原文；仅在明确标题下拆分职责与要求，缺正文或小标题时留空并报告。`publishedAt` 为发布时间，不把 `updatedAt` 作为新发布。地区取源站省市字段，单城市形成省/市路径，多城市原样保留。已验证的 campus 目录在 `commitment` 缺失时按校招处理；明确的实习/兼职类型或标题优先，标题含“实习”时即使平台标为“全职”，也不能充当全职校招。
- 输出原始岗位、字段证据、覆盖报告和十三列工作簿。没有发布日期、学历、分类或后台地点路径的记录保留待补全报告。

## 失败行为与验收

解密密钥/IV 不匹配、接口结构改变、总数变化、重复页、详情 ID 不符或分页不完整时标记来源部分完成并保留已成功记录。空页面不是零岗位证据。新租户仅在探测、回放、完整真实试运行后启用绑定。

回放至少覆盖解密、分页、详情关联、标题拆分、原始发布时间、实习排除、重复与空目录。真实验收记录入口、时刻、总数、详情数和障碍；质量门禁与 SPEC-011 一致。
