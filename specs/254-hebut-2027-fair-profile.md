# SPEC-254 河北工大 2027 届双选会企业岗位

状态：已实现并于 2026-10-20 真实验收五个企业账号；属于 SPEC-238 新增 50 家批次。

## 目标与非目标

采集河北工业大学就业网中，已报名 2027 届秋季双选会且有当前公开招聘岗位的企业账号。候选包括敬业集团旗下江苏敬业钢铁、创新新材旗下山东创新精密、立中集团高校账号、中信集团旗下中信戴卡、太保集团旗下太平洋产险天津分公司。只覆盖该高校账号公开的当期岗位，不宣称集团全网目录完整；不把旧届岗位、其他法人、活动类别、专业方向拆成新岗位，不自动投递。

## 输入与输出

- 每个来源输入高校企业主页；核实账号名称、与 2026-10-16 举行的 2027 届双选会关联及当前招聘简章的全部详情链接。活动报名说明要求企业选择已发布职位信息。仅取 2026-09-01 以后发布、详情主体及标题与目录一致、无社招经验要求的全职岗位。
- 逐岗提取岗位名称、来源发布日期、工作地域、学历、专业及描述；缺失截止日期、具体城市或职责时留空并进入待补全，不用活动日替代发布日期。主体映射依高校账号所列集团/上市主体关系，以来源范围注明子公司或集团账号。
- 输出完整 Collection、证据以及标准岗位信息、严格导入和待补全表；每个不同企业 ID 单独验收。

## 失败行为与可验证验收

账号、活动关联、目录结构、分页、详情主体/标题/发布日期变化时拒绝完整覆盖。单个详情失败保留已采岗位并报告局部失败；目录为零不计入新增有岗企业。离线回放验证目录、详情关联、日期边界、旧届排除与局部失败。真实采集每源 coverage complete、selected > 0 且单源及合表审计通过后，才计入新增家数；结果与限制记入进度文档。
