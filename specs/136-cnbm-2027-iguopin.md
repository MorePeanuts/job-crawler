# SPEC-136 中国建材集团 2027 校招国聘专站

状态：开发中；归属 SPEC-101。

## 目标、输入与输出

从名录 COM0091 中国建材集团有限公司官方招聘公告指向的 `https://cnbmjob.iguopin.com/job-campus` 采集集团 2027 届校招专站公开全目录，以原网站机构树保留实际招聘单位，输出公共快照、信息表和严格导入表。

## 非目标

不采该专站另设的社会招聘、实习或其他项目，不登录或投递；不把招聘起始时间或采集时间写作岗位发布时间。

## 已观察契约

国聘公开专站 `exclusive/info?domain=cnbmjob` 主体为中国建材集团有限公司，校园导航 `/job-campus` 指向项目 `220514553295799224`。`project-company` 机构树载荷为该项目及 `show_all_company=0`，根机构总岗位数 677；`project-job` 公开目录载荷含相同项目、根公司 ID 和 `page=1,page_size=20`。所有页面与树计数、单位 ID/名称、岗位 ID 和类别逐项核对；逐页至末端。正文在岗位列表 `contents` 内，按真实章节提取职责与要求。

## 失败与验收

入口、项目、根主体、目录筛选、分页、岗位身份或单位树不一致时标记覆盖失败并保留证据，不将空结果算成功。回放验证目录页、单位核对、字段与异常；真实验收需 `coverage=complete` 且正式校招大于零，核对源岗位总量与选中量、严格导入及待补全量。
