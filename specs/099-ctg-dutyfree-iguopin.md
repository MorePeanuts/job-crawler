# SPEC-099 中免股份国聘 2027 校招目录

状态：已验收。日期：2026-10-14。归属 SPEC-050。

## 目标与非目标

从 COM0295 中国旅游集团中免股份有限公司所在的中国旅游集团国聘 2027 校招项目 `https://ctgjob.iguopin.com/job-campus` 采集公开岗位。项目公司树包含中免股份本级、其上海数字科技分公司和多个独立法人；仅本级与该分公司岗位纳入，其他子公司即使处于同一“中旅免税”板块也排除。不登录、投递或使用集团品牌代替雇主判断。

## 输入输出与失败行为

页面公开 POST `/api/company/index/v1/project-company` 返回项目公司树，以精确名称和公司 ID 核对本级及上海数字科技分公司。POST `/api/jobs/v1/project-job` 对中免股份公司树分页，`total` 是含独立子公司的全树岗位数，须遍历全部 ID 后精确过滤 `company_id`。列表行已带岗位全文、类型、状态、招聘起始时间、截止日、地点和学历；`start_time` 不是可证实的岗位发布日期，发布日期留空。按 `【职位描述】`、`【任职资格】` 拆分正文，保留原始证据，不调用投递接口。截止时间按源站本地日期判断，已截止、隐藏、非校招记录排除。

公司树身份变化、总数变化、重复 ID、分页短页、详情正文结构缺失或请求失败均报告覆盖不完整并保留此前成功记录。源站没有独立岗位详情接口，完整列表行是职位展开卡片的数据。

## 可验证验收条件

1. 回放测试覆盖两种允许主体、独立子公司排除、分页末端、重复 ID、总数变化、截止日和正文拆分。
2. 独立状态库 `--window all` 实采，全树岗位数闭合，有效本级/分公司岗位大于零、`coverage=complete`。
3. 实采通过后更新正式来源绑定、README、批次验收和归档；Ruff、ty、pytest 通过。
