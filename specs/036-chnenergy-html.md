# SPEC-036 国家能源校招 HTML 分页

状态：进行中，纳入 SPEC-033 剩余来源修复。

## 目标与非目标

从 COM0031 官方 `recTypeSerch?kinds=1&schType=2` 校招目录遍历全部单位、全部页，再以列表截止日期排除已过期岗位；未过期或无截止日期时读取 `annc/showgw?id=...` 详情。不得以第一页或一个单位的结果代表集团全量，不访问登录或申请接口。

## 输入输出

服务器渲染的页面表单以 `pagenum` 从 0 开始分页，其他目录筛选保持空值，`kinds=1`、`schType=2`、`searchtype=job` 固定。页面显示总岗位数、总页数及每条唯一详情 ID。输出为公开有效校招岗位、逐页和逐详情证据、排除数量以及完整性报告；源站没有的日期字段留空。

## 失败行为与验收

每页总数/页数变化、页码不符、重复 ID、空白提前页、详情与目录 ID/标题不符或请求受限，均标记 incomplete 并保留已成功记录。零有效岗位只有在全部页面成功遍历、列表日期均已截止且唯一 ID 数与总数吻合时才算完整。回放验证分页、重复、详情关联、截止日边界；真实运行确认全页终止。
