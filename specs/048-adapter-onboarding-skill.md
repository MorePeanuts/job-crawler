# SPEC-048 项目内适配器接入 Skill

状态：已实现并完成离线与历史快照验收（2026-10-14）。

## 目标与非目标

将已验证的单站/批量招聘适配器接入流程整理为项目内 `.agents/skills/add-recruitment-adapters/` skill，涵盖探索、spec、实现、离线与真实验收、复用快照汇总、发布和归档。复用项目规范，不复制平台实现，不要求 PR。本次不新增真实站点、不采集网站、不调用 LLM、不修改已有交付表格。

## 输入输出

输入为企业/URL、已有来源 ID、目标数量和范围；缺少范围时使用项目默认校招口径。输出为可发现的 SKILL.md、必要的实现/交付参考、UI 元数据，以及只读批次验收脚本。AGENTS.md 和 README 提供发现及调用入口，其他代理可以直接阅读同一文件。

Skill 要求 source_id 与 company_id 分开计数；以 coverage=complete 且 selected>0 的企业为有岗位企业，零岗位、重复入口、部分覆盖不能凑足数量。来源身份、平台参数、日期、原始证据不能猜填。正式绑定只纳入真实验收通过的来源；试跑使用临时绑定。缺口及替代必须遵循用户范围。

交付复用已采原始快照和模型缓存，保留来源实际采集时刻；bundle 后由程序核对源报告、企业数、岗位数及两份工作簿，再 archive --publish。开发状态库放在归档目录之外，避免已注册的 SQLite 被连同目录删除；不默认复用旧批处理脚本的内置状态库路径。用户没有要求长期保存原始快照时不自动 --pin。

## 失败行为

达到预算或出现登录/验证码/不明确范围时保留 partial/blocked 与具体障碍，不无限重试、不虚构岗位。只读验收发现重复来源、报告/文件数量不一致、缺企业或覆盖不全时退出非零，不能标为已交付。字段待补全造成总体 partial 不等于目录失败，分别报告 selected、review、exported 与表格行数。skill 只定义后续流程，不授权当前创建任务去访问站点或消费模型额度。
