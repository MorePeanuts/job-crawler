# SPEC-086 渤海银行 2027 校招

状态：已实现并真实验收。日期：2026-10-14。归属 SPEC-050。

## 目标与非目标

接入 COM0280 渤海银行股份有限公司公开的 `https://campus.51job.com/bhyh2027/head.html`。完整遍历总行管理培训生、总行培训见习生、分行管理培训生、分行培训见习生四个导航页面，并以页面中的独立岗位申请 ID 计数。分行作为本行分支纳入；“渤银理财招聘”属于单独主体，不纳入本来源。不点击申请链接或提交简历。

## 输入、输出及失败行为

输入是四个公开静态招聘页面及分行详情页加载的公开 `job.js` 单位数据。核对导航、每个岗位 ID、租户 ID、分行地区与详情脚本的分行名称；总行岗位按独立申请链接关联。输出使用共同 `Job` 模型，保留页面的招聘对象和招聘要求；源站未给出的岗位职责、发布日期、截止日及详细工作地址留空，不推算为采集日。任一页面、导航、岗位身份或地区映射变化时报错并保留已采岗位与覆盖缺口，不把部分结果当作全量成功。

## 可验证验收条件

1. 离线回放验证四页面覆盖、分行城市与详情脚本关联、渤银理财排除、重复 ID 和局部失败。
2. 当日真实全量采集核对四页面所有申请 ID、各范围数量和 `coverage=complete`，且正式校招有效岗位大于零。
3. 验收后启用来源、更新阶段汇总，完成审计、归档和质量门禁。
