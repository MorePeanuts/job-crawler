# SPEC-149 浙江交通集团 2027 校园招聘

## 目标

接入名录 COM0075 浙江省交通投资集团有限公司的官方 2027 校园招聘。集团网站 `https://jt.hzshyy.com/content/82659` 公布 22 家成员单位的岗位入口和计划人数，`https://jt.hzshyy.com/content/82696` 单列集团总部 45 人管理培训生。适配器必须遍历两份公告的全部 23 个入口及每个入口公开的逐岗目录，保存实际招聘单位、部门、职责、要求、地点和公告发布时间。

## 非目标

不把计划招聘人数当作岗位条数，不把公告正文表格里的同名“应届生”按标题合并。不采社招、内招和实习，不调用投递接口。源没有逐岗截止日期时保持空值，不用公告更新时间或采集时间代替发布日期。

## 输入、输出与失败行为

输入是两份集团官方 HTML 公告及其指向的 `dhr.cncico.com` 公开公告 ID。按公告表格读取每单位唯一 PC `needsId` 和移动 `announceId`，校验 22+1 个链接、每单位计划人数和公告身份。公开 `recruitannounce/detail` 返回公告发布日期及状态，`get-needs-detail` 返回该公告全部岗位、唯一岗位 ID、职位类别、招聘方式和完整正文。按每公告独立 Scope 核对岗位目录数量、公开状态、校园招聘与外部招聘标记；页面表格逐岗链接与接口 ID 应一致。输出原始快照、岗位信息表、严格导入表和待补全报告。任一公告或岗位身份不符、链接缺失、接口结构变化、空列表或请求失败时该 Scope 保留 partial，其他已成功记录保留，不以零岗位冒充成功。

## 可验证验收条件

1. 回放覆盖两份公告、23 个单位、计划人数与实际岗位数不同、同名岗位不同 ID、内招/社招排除、详情身份冲突及局部失败。
2. 实站 23 个公告入口全部完成，逐公告 `expected=listed=unique=details`，集团总覆盖 complete，正式校招岗位大于零，核对官方计划人数之和但不把它当岗位数。
3. Ruff、ty、pytest 通过，README 与批次验收记录载明源站日期和导入限制。

对应测试：`tests/test_zjjt.py`。
