# SPEC-014 文晔静态校招页面

状态：已实现并真实验收，2026-10-12。

## 目标与非目标

接入 COM0104 文晔科技在 `campus.51job.com/wtmec/job.html` 的公开静态岗位页面。该页面将列表与详情放在同一批 `.job-item` 元素内；解析全部卡片并校验每条的公开申请链接。只针对这一个经过观察的活动页结构，不把 `campus.51job.com` 上其他定制活动页自动纳入支持，也不点击投递或登录。

## 输入输出与范围

- Crawl4AI 打开固定招聘页，采集本轮 HTML 并保留页面证据。只在页面含招聘导航、非空 `.job-item`、每卡片唯一标题与合法申请链接时建立范围；所有卡片必须成功解析，不能跳过有异常的卡片仍报告 complete。
- 岗位 ID 取每卡片申请链接的 `jobid`，核对本页无重复。`job-desc` 明确标注的“工作地点”“岗位职责”“任职要求”分别提取；多城市保持原文。源页未显示发布时间和截止日期，字段留空，不用采集日或 URL 的年份推断。
- 每次运行输出原始岗位、证据、覆盖和十三列工作簿。源页面没有额外详情请求；每日时间窗口按 SPEC-009 的无日期岗位规则，基线建立前不把存量当日新增。

## 失败行为与验收

页面不可达、卡片为空、标题/申请 ID 缺失、申请 URL 异常、重复 ID 或字段标签变化时阻断该来源的 complete 覆盖，保存已取到的证据及问题。离线回放覆盖四卡片、职责/要求分段、多城市、无发布日期、重复/缺失链接；真实运行核对卡片数、唯一 ID 数和页面结束条件。质量门禁与 SPEC-011 一致。
