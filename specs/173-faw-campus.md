# SPEC-173 中国一汽校园项目目录

状态：已实采验收；SPEC-156 B 组 COM0047。

## 目标与范围

官方 zhaopin.faw.com.cn 跳转至 faw-zhaopin.hotjob.cn。校园主页公开四个正式项目：应届生 205701、博士生 205601、双百 205801、三地 203201，均 recruitType=1；红旗学院及实习生为 recruitType=12，本轮不纳入。覆盖全部单位，不把首屏十条或应届生单项目当作集团全目录。不登录、不投递。

## 输入输出

从校园页面读取所有 positionList 链接，校验项目类型和身份。逐项目打开实际路由，从公开观察到的 GET listPosition 请求按 currentPage 遍历，pageSize=10、externalProjectStr 指定本项目；首项目本轮 376 条、38 页。每页计数、页码、总页数、岗位项目 ID 和 recruitType 必须一致。

详情使用卡片对应 pb/posDetail.html 和页面公开 POST listPositionDetail；复用 Hotjob 职责、要求、地点树及日期解析。详情 ID、项目、租户及标题核对；匿名 canDelivery=false 不等于停止招聘。首次发布日期与更新日期区分，保留真实截止日期与用人单位。不按人数或城市复制岗位。

## 失败行为与验收

缺项目、额外未知类型、分页总数变化、提前空页、跨项目/租户详情均保留已成功结果并报告覆盖问题；某个项目失败不得吞掉其余项目。空目录必须有业务成功、计数 0 与空数组互证。回放覆盖四项目、跨页、详情错配和失败隔离；真实全部目录闭合、公共分类导出及只读审计通过后启用正式绑定。
