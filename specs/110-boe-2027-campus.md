# SPEC-110 京东方 2027 全球校招

状态：真实覆盖已验收。日期：2026-10-15。归属 SPEC-101。

## 目标与非目标

接入名录 COM0137 京东方科技集团股份有限公司官方 `https://campus.boe.com/` 公布的 2027 全球校园招聘岗位。官网及高校转载的官方简章均指向这一入口；包含集团官网公开招聘范围并保留逐岗实际单位，不把分子公司标作总部。排除社招、实习和关闭岗位。

## 输入、输出与站点契约

官方“招聘职位”页为 `https://campus.boe.com/custom/xzzw?hideMenu=1`。2026-10-15 观察到页面先以 `Category=[15]`、`type_code="1"` 请求 `boe.yuegekeji8.cn/api/Jobad/GetJobAdPageList`，只得应届生 640 条；公开招聘类型字典另有博士生 41、提前批 0。将 `type_code` 清空可得到完整 684 条目录，其中 3 条实习生在后续处理排除。API `data.counts` 与 `data.list`、零起始页码可用于闭合全目录，列表每条包含 `Id`、标题、招聘类型、业务板块、类别和地点。详情从同域 `GetJobAdInfo?jobAdId=Id` 返回同一 ID、职责、要求、`PostDate`、`EndTime`、状态及业务板块。跨域 API 只用浏览器公开的无凭据请求，保留每页和详情证据。实际招聘法人未明示时保留空白；`yebk` 业务板块按原文存单位字段，不写成法人。官网公告称招聘结束的职位会从站点移除，因此仅采集实时仍展示的目录，不用公告预估“2000+需求”冒充岗位总数。
