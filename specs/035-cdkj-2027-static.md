# SPEC-035 长电科技 2027 校招活动页

状态：进行中，纳入 SPEC-033 剩余来源修复。

## 目标与非目标

将 COM0381 从名录中已过时的 `cdkj25` 入口切换到长电科技公开的 `cdkj26/job.html` 页面，采集该页 2027 届「芯火计划」和普通应届生岗位的每个城市投递项。不猜测未展示的岗位，也不通过申请页面登录或投递。

## 输入与输出

输入为 `https://campus.51job.com/cdkj26/job.html` 的公开页面。页面分别以 `.jobtitle` + `.jobinfo` 与 `.jobs` + `.jobinfo1` 表示两类岗位，城市申请链接使用 `xyz.51job.com/external/apply.aspx` 的 `jobid` 与 `ctmid=6628681`。输出为每个唯一申请 ID 一条岗位记录，保留页面的专业、学历、培养方向或岗位要求原文及申请链接；无明确发布时间/截止时间则留空。

## 失败行为与验收

页面不再标明 2027 届、岗位组/申请链接缺失、`ctmid` 改变、申请 ID 重复或组内字段缺失时，来源标记未完成并保留证据，不把部分结果说成全目录。通过条件是所有分组及城市链接均计入，唯一 ID 数与页面申请链接数一致；真实运行 `coverage=complete`，并有多城市、重复 ID、字段缺失的离线测试。
