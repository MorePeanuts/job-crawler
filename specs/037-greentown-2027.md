# SPEC-037 绿城中国 2027 校招旧版北森页面

状态：进行中，纳入 SPEC-033。

## 目标与非目标

为 COM0166 的旧版北森校园站点按公开 HTML 表格和 `PageIndex` 遍历全部校招岗位，读取逐岗位详情。该站不能沿用新版 `/api/Jobad/GetJobAdPageList` 契约；不猜测接口，也不通过登录投递。

## 输入输出

入口 `https://gtgroup.zhiye.com/campus/` 包含岗位表格、总记录数和页数；详情链接为 `/zpdetail/{id}`。输出为每个唯一详情 ID 的岗位、工作地点、分类、发布时间、截止日期及职责和任职资格原文，未公开的日期留空。

## 失败行为与验收

目录总数/页数变化、提前空页、重复详情 ID、详情标题/招聘类别与目录不一致、职责或任职资格缺失，均报告不完整。真实运行须完成全部页面和详情，唯一 ID 数与记录总数一致；离线测试验证分页、重复与详情关联。
