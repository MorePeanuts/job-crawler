# SPEC-006 导出截止时间

状态：已实现并完成真实快照核验。

## 目标与契约

按用户最新要求修正岗位导入模板：在原十一列后追加第十二列 `截止时间`，对应 `Job.deadline`。公共模板、严格导入表和岗位信息汇总表采用同一列顺序。前十一列、岗位集合、分类、来源时间及覆盖报告保持不变。

有截止时间时保留采集字段的原始文本及精度（日期或 ISO 日期时间）；未提供则为空，不能用采集时间、公告时间或推算日期填补。字段非必填，不影响已有截止筛选与待核验规则；非空但无法解析的日期仍保留待核验，不转换成虚构日期。模板说明注明本列为文本、可留空。

本轮从最后的分类快照离线生成新版汇总，不重新采集、不调用 LLM，使用原筛选时刻以保留原表记录。旧版输出留存，新版作为本次交付。历史 spec 中的十一列描述由本 spec 的十二列契约取代。

## 失败与验收

- 模板表头与导出字段不一致时报错；非法 Excel 字符或超长值仍拒绝静默截断。
- 测试覆盖日期、精确时间、空截止值及不可信公式文本；严格导入表和汇总表第十二列一致，筛选范围包含新列。
- 对已有 4,611 条汇总逐行比较前十一列未变；第十二列与对应岗位 deadline 一致，缺失保持空白，原有分类和二十企业覆盖保持不变。
- uv、Ruff、ty、pytest 通过，README 更新列定义与最新输出路径，检查新增列显示。

功能分支延续尚未合并 main 的 `feat/job-taxonomy`，不丢弃已验收实现，不直接合并 main。
