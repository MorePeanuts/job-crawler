# SPEC-006 导出截止时间

状态：已实现并完成真实快照核验。

## 目标与契约

按用户最新要求修正岗位导入模板：在原十一列后追加第十二列 `截止时间`，对应 `Job.deadline`。公共模板、严格导入表和岗位信息汇总表采用同一列顺序。前十一列、岗位集合、分类、来源时间及覆盖报告保持不变。

按用户追加要求，Excel 的截止时间统一为 `YYYY-MM-DD` 文本，例如 `1970-01-01`，不带时分秒。精确时间先按项目 Asia/Shanghai 时区取日期；源值只有日期时直接保留该日期。未提供则为空，不能用采集时间、公告时间或推算日期填补。非空但无法解析的日期在表中留空，由既有筛选规则进入待核验，原文保留在 JSON。模板说明同步更新格式。

原始 `Job.deadline` 与 JSON 保留完整时间，筛选仍使用原有精度；此次仅修改表格显示，不能因丢弃时分秒延长岗位有效期。

本轮从最后的分类快照离线生成新版汇总，不重新采集、不调用 LLM，使用原筛选时刻以保留原表记录。旧版输出留存，新版作为本次交付。历史 spec 中的十一列描述由本 spec 的十二列契约取代。

- 测试覆盖日期、精确时间、空截止值及不可信公式文本；严格导入表和汇总表第十二列一致，筛选范围包含新列。
- 对已有 4,611 条汇总逐行比较前十一列未变；第十二列与对应岗位 deadline 的上海日期一致、全部匹配 YYYY-MM-DD，缺失保持空白，原有分类和二十企业覆盖保持不变。
- uv、Ruff、ty、pytest 通过，README 更新列定义与最新输出路径，检查新增列显示。
