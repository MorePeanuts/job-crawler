# SPEC-184 上海钢联官网校园招聘

## 目标与非目标

接入 B 组 COM0250 上海钢联电子商务股份有限公司官网 `/career/` 的完整校园目录。页脚法人及官网股票代码 300226 核对身份。仅纳入正式校园岗位；社会招聘、公众号其他机会不在已验证网页目录范围，实习按公共规则排除，不把零正式岗位计为有岗位企业。

## 输入、结构和输出

入口 `https://about.mysteel.com/career/?id=recruit`。实际引用的公开 `recruit-detail.js` 在页面初始化时完整渲染 `#recruit-box` 和 `#recruit-content`，点击仅切换显示，不分页、不请求详情。栏目顺序为业务板块、职能板块、应聘须知；三块 DOM 均存在，包括隐藏职能岗位。前两块分别建立 Scope，全部 `dl` 为独立岗位，`dt` 为源标题，`dd p` 提供岗位职责及任职要求。第三块仅福利待遇和投递方式，不拆为岗位。禁止请求、提交投递。

源无独立 ID，键用栏目 ID 和唯一标题，重复标题使该范围失败。列表全文直接解析，增量指纹包含完整卡片与应聘须知，使用 before_detail/remember，不另取详情。源无发布时间/截止日期保持空，学历保留原要求交公共补全，工作地来自应聘须知明确工作地点上海市宝山区园丰路68号。每项保留原 URL 和页面证据。

## 失败行为

身份、栏目与内容数量不符、空目录、未知正文段落、额外详情/分页/附件、栏目丢失均报告失败，不能当作零岗位。每栏目错误隔离。范围结束依据是已验证脚本全量 DOM 数量，而非可见页。未来新增未验证项目要求更新规范与契约。

## 验收

- 离线验证隐藏职能岗位、两个 Scope 计数、正文/原日期缺失、实习排除、重复标题及结构变化失败。
- 全量质量门禁通过后临时绑定实采；本次已探测 2+2 条，全部明确标题为实习生，预期正式有效 0；以实际完整实采为准。
- 严格审计零岗位，成功后正式启用，加入 B 组输入；零正式岗位不增加有岗位企业数。
