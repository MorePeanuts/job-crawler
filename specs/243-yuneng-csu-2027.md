# SPEC-243 湖南裕能中南大学 2027 届双选会岗位

状态：已实现并于 2026-10-20 真实验收，属于 SPEC-238 新增 50 家批次。

## 目标与非目标

采集中南大学就业信息网 `https://career.csu.edu.cn/largefairs/company/id/1312/sid/104/stype/1` 上湖南裕能新能源电池材料股份有限公司在 2027 届秋季第二场双选会的全部公开招聘行。学校展位报名表给出与名录一致的完整法人名称及统一社会信用代码、2026-10-25 举办时间和四条全职岗位。范围仅是该企业在本场双选会的公开岗位，不延伸至企业其他渠道、其他场次或历史岗位。

## 输入输出

- 校验页面标题含「2027届」及中南大学双选会，报名表中的单位全称、统一社会信用代码与当前观察主体一致；只解析 `#lTable` 中「招聘内容」之后、带 `.apply_job[data-id]` 的岗位行。当前四行的申请 ID 各不相同；以后以页面实际全部行和唯一 ID 为准，不硬编码数量。
- 每行需有职位、专业、人数、学历和「全职」性质。保留专业原文作为要求，来源未提供逐岗职责、工作地点、发布时间和截止日期时留空并进入待补全；不得以活动时间充当岗位发布时间或截止日期，也不调用投递接口。
- 无分页控件且公开岗位行全部遍历时设目录终点；若页面出现分页、行重复或身份改变，报告覆盖失败。岗位唯一键为学校申请 ID，同一岗位不按人数复制。

## 失败行为与验收

非 2027 届活动、法人不一致、缺失岗位身份或招聘字段、非全职混入、动态分页出现时不能报完整采集。逐行解析错误保留其他成功行并报告 partial。离线回放验证身份、ID、行解析、重复与局部失败；真实全量验收核对页面四行、selected、信息/严格工作簿与 coverage，通过后正式绑定并计入 COM0415 一家。
