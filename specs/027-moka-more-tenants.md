# SPEC-027 Moka 新租户

## 目标

将来源 COM0172 牧原、COM0198 温氏、COM0202 徐工接入现有 Moka 校招平台适配器。逐站验证租户、站点 ID、无筛选分页总数、详情关联和公开岗位正文。

## 非目标

COM0465 世茂现有链接返回“页面不存在”；COM0500 东方证券入口显示社会招聘且无职位。本规范不把它们标为已接入，也不操作登录或投递。

## 输入输出

输入为来源列表、采集窗口及公共配置；输出为岗位快照、覆盖报告和符合模板的候选 Excel。源站没有公开的日期、学历或地址必须留空。

## 失败行为

租户 ID、分页总数、详情 ID 或正文不一致时该来源为 partial，保留已采集记录和证据，不能绑定 ready。

## 验收

- 逐站从原 URL 到公开 `#/jobs` 页面，核对观察到的 `orgId`、`siteId` 与无筛选目录。
- 全部分页唯一岗位数等于站点报告的总数，详情与目录 ID 逐条一致。
- 三站各自真实运行覆盖检查 complete 后再绑定；离线回归覆盖租户配置与异常边界。
