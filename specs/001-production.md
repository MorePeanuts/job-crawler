# SPEC-001 正式采集框架

状态：开发中。2026-10-10。覆盖本轮正式开发需求；与历史方案冲突时以本规范为准。

## 目标与非目标

建立可运行的 Python CLI/SDK：维护来源、调用版本化适配器、采集当前岗位、按时间筛选、验证模板并导出一份 Excel。新网站通过适配器开发接入，所有已导入来源必须能查询接入状态。

不实现零配置任意网站、定时调度、自动投递或验证码破解；本轮不将名录的全部来源自动视为已支持。不修改原始附件。

## 输入

- 来源 CSV：`企业ID,主体名称,招聘官网,备注`。一企业允许多个入口，通过来源 ID 独立绑定适配器；保留无链接企业，忽略空行，非法行单独报告。导入先校验再写入，重复来源 ID、非法 URL 拒绝。
- `sites/bindings.toml`：来源 ID → 适配器、版本、校招范围、后台公司名以及站点参数；平台行为在代码中。
- 项目配置：并发/速率/请求超时、请求预算、LLM 配置、分类路径及明确的字段映射。默认 LLM 使用 `deepseek-flash` 和环境变量 `DEEPSEEK_API_KEY`，可更换模型、OpenAI 兼容端点和环境变量名。
- 用户模板保存在包资源中，保持 11 列顺序：公司、岗位名称、工作类型、一级分类、二级分类、学历、地点、详细地址、岗位职责、任职要求、申请链接。

## 数据与筛选

- 源岗位 ID + 必要的批次/单位构成稳定唯一键，跨来源不进行模糊合并。名录公司名与招聘子单位分开保存。
- `all`：当前目录仍展示且未截止的岗位。明确关闭的岗位排除，未提供截止日期的保留；有截止原文但无法解析则进入待核验。
- `day` / `week`：自执行时刻往前 1 / 7 天；`month`：往前一个日历月（月底向该月最后一天截断）。区间 `[since, as_of]`，默认 Asia/Shanghai，可固定 as-of 复现。
- 源站只有日期时，发布日期按该日的时间区间与窗口相交判定，报告日粒度；截止日期有效至当天结束。有精确时分秒则按该时刻判定。首次发现时间不替代发布日期。未来发布时间和无法解析的非空日期须报告。
- 窗口模式缺少发布时间时不进入导入表，保留完整原始岗位和待核验原因。不能将筛选后的行数与未筛选源总数直接比较。

## 导出与导入约束

- 每轮生成 `jobs.xlsx`，保留模板的表头、枚举与说明，删除示例行，不添加列或报告工作表。字段映射与模板一致，扩大数据验证范围。源站文本强制字符串，避免公式执行。
- 公司、岗位名称、工作类型、学历、一级与二级分类必须有效。分类需在明确配置的父子关系中，不从模板两列的行号推断父子关系。没有分类树时相关记录进入 `review.json`，不可虚构分类以填满表格。
- 多学历只在存在明确“最低学历”语义或配置规则时规范化。地点不补造未知行政区；未达到用户导入格式的值留待核验。超出 Excel 字符容量的必需内容不静默截断。
- `jobs.json` 保存采集到的所有岗位及证据引用，`review.json` 保存待补全/无法判定记录，`report.json` 保存覆盖、筛选、导入数量及错误。SQLite 保存运行、请求检查点、岗位与首次发现时间。没有可导入行也生成空模板及报告。
- 覆盖状态与导入可用状态分开：抓取完整不等于全部行可导入。任务只在覆盖完整且没有待核验/待补全时返回退出码 0；部分或阻塞返回 2；配置错误返回 1。

## 执行与恢复

- 所有站点请求通过统一 Crawl4AI 会话。观察接口与调用共用会话。重试有上限，对认证/权限问题直接报告。证据文件与日志脱敏。
- 各来源独立保存结果；某页或详情失败仍保留此前岗位，失败源不掩盖其他源。核验源总数、唯一键、重复页、批次与公告展开。
- 同一运行恢复需校验配置/版本/参数指纹和时间范围；始终重取列表，只有当前列表引用且处于同一运行的成功详情可复用。过期运行要求重新采集。禁止复用旧列表宣称当前完整。
- 报告区分未适配、空入口、403/登录、解析错误、数量不一致、预算用尽、字段不符、日期未知。

## 验收

1. 导入用户名录并报告有效企业、有效入口、空入口和非法尾注；原文件不改变。
2. 配置增补入口、绑定适配器可查询；未知适配器必须报错，不能抓零行成功。
3. 回放测试覆盖分页、公告展开、复合键、空目录、数量变化、局部失败、恢复失配。
4. 固定时钟验证当天截止、精确截止、日/周/月边界、未知/错误日期和非当前岗位。
5. 用用户模板导出并重新读取，验证 11 列顺序、示例清除、枚举/父子关系、公式安全、空输出与待补全报告。
6. 无 key 的纯规则适配器正常运行；LLM 按配置调用，错误/截断/无引证/预算超限均可报告。
7. README 记录安装、来源维护、运行、窗口、恢复、LLM、报告、适配器开发及限制。静态检查和离线测试全部通过，真实验证另列。
