# SPEC-241 天山铝业河北工业大学公开校招生目录

状态：已实现并于 2026-10-20 真实验收。属于仍在进行中的 SPEC-238，COM0455 已启用正式绑定。

## 目标与非目标

采集河北工业大学就业站上经企业认证的「天山铝业集团股份有限公司」主页 `https://career.hebut.edu.cn/company/index/id/19244.html` 所列全部公开招聘岗位。当前主页仅有 5 条「校招生」职位，分别位于上海总部、广西靖西和新疆石河子；页面的企业名与名录主体一致，各详情返回企业主页的同一 ID。该来源限于企业在该高校就业站发布的完整公开目录，不声称覆盖企业在其他渠道的全部岗位。

输入是主页当前 HTML 与每条 `/correcruit/content/id/<id>.html` 详情。非目标是历史岗位、其他企业账户、站内报名或扩展到社招平台；不点击投递，不猜测未给出的截止日期或市区。

## 输出和约束

- 主页必须仍标识天山铝业完整主体名称，且全部职位由 `.lizw` 链接列出；逐条从当前链接发现详情 ID，不硬编码观察到的五个 ID。岗位标题必须明确含「校招生」，主页与详情标题、主体、发布日期一致；岗位 ID 不重复。
- 从详情提取正式岗位职责及专业要求，保留来源原文与人数；源「实习期工资」不代表实习岗位，工作性质以「校招生项目」「正式录用：签订劳动合同」确认。地点、学历、发布日期取详情明确字段，截止缺失留空。源招聘人数不拆分为多条岗位。
- 逐一打开全部详情，确认详情返回同一企业主页 `/company/index/id/19244.html`，完成数等于主页列表数时才标记目录 terminal。每行附主页和详情证据；混合来源或详情异常保留已成功行并报告 partial。

## 失败行为与验收

主页无列表又无明确零状态、分页结构出现变化、主体或详情关联不符时不报完整采集；只有明确范围外行才可排除。离线测试覆盖主页身份、目录 ID 去重、标题/日期关联、详情字段、局部失败及零目录；真实全量采集需核对 5 条列表、5 条详情、有效岗位与导出，之后再写正式绑定并纳入 SPEC-238 汇总。目标公司数按不同 `company_id` 计算，不以五条岗位当作五家企业。
