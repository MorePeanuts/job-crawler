# SPEC-072 歌尔股份 Hotjob 校招

状态：已实现并真实验收。日期：2026-10-14。归属 SPEC-050。

## 目标与非目标

接入 COM0208 歌尔股份有限公司的公开 Hotjob 校招入口 `https://goertek.hotjob.cn/SU65dd9ebd1c240e4b11c4f491/pb/school.html`。探测时 `recruitType=1` 全目录为 64 条，分页六页，列表 `company` 均为「歌尔股份」。逐页、逐详情核验后输出仍在展示且未截止的正式校招岗位。

不把海外校招、实习、社招或未标注为歌尔股份的其他主体混入；官网上的岗位大类宣传卡片不替代真实目录。

## 输入输出与失败行为

复用 Hotjob 校招表单列表、地点树和详情接口，绑定歌尔专用域名及租户 ID。每条列表的 `company` 必须准确为「歌尔股份」才归本主体；其他主体计入范围外。核对分页总数、唯一 ID、详情 ID 与 `recruitType`；日期、学历、地点和描述以源站字段为准。输出程序生成的信息表、严格导入表和待补全记录。

未知主体、接口模式改变、分页缺口、详情失败、期限或访问阻塞时 coverage 非 complete，保留已成功岗位及证据，不虚填导入字段。

## 可验证验收条件

1. 离线回放验证歌尔股份保留、其他主体排除、详情及分页身份核验。
2. 真实目录 `expected=listed=unique`，本主体岗位和范围外岗位计数闭合，`coverage=complete` 且有效正式校招大于零。
3. 真实验收通过后更新来源 URL 与正式绑定，并纳入 SPEC-050 汇总和归档。
