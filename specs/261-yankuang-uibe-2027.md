# SPEC-261 兖矿能源高校 2027 届在招职位

状态：已实现并于 2026-10-20 真实验收 1 岗；属于 SPEC-238 新增 50 家批次。

## 目标与非目标

采集对外经济贸易大学就业站 `https://aeo.uibe.edu.cn/front/zpxx.jspa?tid=2098326250287316994` 中兖矿能源集团股份有限公司 2027 届招聘页面的全部「在招职位」链接，并逐条核对公开详情。高校正文称兖矿能源为山东能源集团旗舰资产。本来源只代表这份高校公告的在招职位，不扩为集团全网目录或其他招聘项目。

## 输入与输出

- 输入为公告列表及其职位详情；从所有 `zwxx.jspa` 链接读取岗位 ID 与公告 ID，保证 ID 唯一、同公告，并验证详情岗位名、公司、届别和链接身份。当前观察为一条「财务管理」。
- 列表「更新时间」不是职位发布日期，不导入；详情明确「发布于 2026-09-11」才作为发布日期。工作地、专业和岗位要求来自详情；没有职责或截止日期时留空。元信息招聘人数 5 是名额，不是五条岗位。
- 输出标准 Collection、采集证据及岗位信息、严格导入和待补全文件。

## 失败行为与验收

列表身份、届别、岗位链接或详情关联失败时保留错误；可访问的其他成功详情继续保存，不将部分失败视为完整。离线回放核对列表新增岗位、详情 ID/标题、日期语义和部分失败。真实采集 coverage complete、selected>0、单源与合表只读审计通过后计入家数。
