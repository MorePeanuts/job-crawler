# SPEC-016 鞍钢静态校招岗位页

状态：已实现并真实验收，2026-10-12。

## 目标与非目标

接入 COM0121 鞍钢集团在 `campus.51job.com/ansteel2026/job.html` 的公开静态招聘岗位页。该页有招聘企业切换栏，每个企业的岗位卡片与详情由站点脚本直接呈现在 HTML；必须逐个切换并解析所有企业目录，不把默认显示的鞍山钢铁误作集团全量。不根据前程无忧域名猜测其他活动页的结构，不登录、投递或补造公告中未给的发布日期。

## 输入输出与范围

- Crawl4AI 打开固定页面，读取 `.jobtype > div` 全部企业选项；按索引逐个点击，核对激活项与当前 `.joblist .jobs` 卡片，逐企业建立范围与证据。页面没有可见分页控件或相关职位列表接口。所有非空目录的 `.jobs` 卡片必须有 `.jobtit` 标题、`.jobinfo` 资格及唯一的公开申请 `jobid`，不因默认折叠而跳过。空目录只有在源页明确显示无岗位时才能算完成。
- 从每卡片的“学历要求”“专业要求”“工作地点”标签提取原文；单卡片有错字或缺某个标签时，保留资格全文、缺项置空并给字段警告，不以标题推断。资格全文放任职要求；页面未给岗位职责、发布时间、截止日期则留空。招聘企业取当前选项，岗位名保留原文；导出公司名仍按来源清单的主体名称，子单位放单位字段。
- 输出原始岗位、证据、覆盖与十三列工作簿；每日无日期岗位按 SPEC-009 基线规则。

## 失败行为与验收

空卡片、重复或不合法申请 ID、岗位介绍整体缺失、某企业选项切换失败、分页/接口出现导致静态范围无法证明时，保留成功记录并阻断 complete。单字段标签缺失不阻断目录覆盖，但不得猜测补值。离线回放覆盖多企业切换、多卡片、学历、地点、缺失日期、重复 ID；真实运行核对所有企业选项的卡片/申请链接数量、唯一 ID 与各目录结束条件。质量门禁与 SPEC-011 一致。
