# SPEC-241 亨通集团广东工业大学 2027 届宣讲关联岗位

状态：已实现并真实验收，2026-10-20。归属 SPEC-238 的第 37 家。

## 目标与非目标

- 采集 [广东工业大学亨通集团 2027 届宣讲会](https://career.gdut.edu.cn/teachin/view/id/191542) 下方「职位列表」全部 7 个带独立职位 ID 的全职岗位，并逐条访问详情核对标题、集团账号、发布日期。公告正文里的六个宽泛「招聘岗位」职类是宣传方向，不能与七条具体岗位重复计数。
- 不把宣讲日期 2026-10-20 当作岗位发布日期或截止日期，不从字体混淆的详情正文猜测职责。学校账号范围不代表集团全网完整校招目录。

## 输入输出与失败行为

- 输入为宣讲会页 HTML 与七条关联详情；输出七个唯一 ID 的岗位及列表给出的地点、学历、专业和详情明示的发布日期，另有链接证据和一个完整 `Scope`。
- 当届公告、账号、列表页结构或行数、ID 与详情标题/主体不一致时记录 source_changed/局部失败；不能把详情失败当作成功岗位。来源仍显示投递入口且无截止日的行进入信息表，不能伪造缺失字段。

## 可验证验收条件

1. 离线测试校验七条唯一 ID、全职属性、主体和详情对应；增加第八条或详情错配会失败。
2. Crawl4AI 实采七条详情、coverage complete、selected 大于零，单源审计通过后启用绑定。
3. SPEC-238 合表中 COM0131 只占一个新增企业 ID。
