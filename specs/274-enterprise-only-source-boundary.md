# SPEC-274 企业招聘来源边界纠错

状态：已实现，2026-10-20 已撤销非企业来源绑定并发布企业入口子集。用户确认项目只采集企业官方招聘入口及其实际指向的招聘平台，高校就业网站不应绑定为企业正式适配器。

## 目标与非目标

- 正式来源必须是企业官方招聘入口或由企业官方入口明确指向的招聘平台。高校就业网的企业账号、双选会展位和招聘公告只能作为寻找企业入口的研究线索，不能作为该企业完整、稳定的招聘目录。
- 清理当前已启用的高校就业网站及不属于企业入口的省级人才网绑定，恢复或清空 `sites/sources.csv` 的“招聘官网”列；保留旧快照作为历史证据，但不纳入企业官网口径汇总。
- 纠正 2026-10-20 “新增 50 家”交付口径，单独发布该批中符合来源边界的企业招聘站子集。本文不删除历史原始证据、不伪称其岗位内容虚假，也不承诺尚未找到的企业入口已适配。

## 输入输出与失败行为

- 输入为 `sites/sources.csv`、`sites/bindings.toml`、2026-10-20 批次 50 份已验收快照及项目原始来源约定。当前已绑定 44 个高校就业网来源，另有湖南人才网 `COM0314` 1 个非企业入口；其中本批分别占 41 家、218 岗和 1 家、17 岗。
- 输出为只保留企业招聘入口及其所链平台的绑定、来源清单、纠正后的验收说明和企业来源子集表。原 50 家混合来源表保留并明确标为不符合企业官网来源范围的历史结果，不得继续称为“50 家企业官网适配完成”。
- 无法确认企业官方入口或官方跳转证据时，来源保持待适配。高校岗位可以独立留在历史快照，但不得代替企业站点的全目录覆盖；页面仍可访问或单校岗位数闭合不算正式验收。

## 可验证验收条件

1. 默认绑定中没有已知高校就业网或湖南人才网来源；运行前检查可拒绝把这些站点重新绑定为企业适配器。
2. 50 家旧批次按来源复核后，仅 8 家、172 条岗位属于企业官网或官方招聘平台；这 8 家的离线子集合表及严格导入表通过只读审计。
3. README 和批次验收明确旧混合表的限制、目前缺口和恢复正式 50 家所需条件；Ruff、ty、pytest 全部通过。
