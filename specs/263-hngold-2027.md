# SPEC-263 湖南黄金洞矿业 2027 年招聘计划

状态：已实现并于 2026-10-20 真实验收，归属 SPEC-238。

## 目标与非目标

- 采集湖南人才网 [黄金洞矿业公告](https://qz.hnrcsc.com/ptemp/#/positionB/consultdetailss?termTaxonomyId=931&id=1012051) 唯一的「2027年招聘计划表.xlsx」附件中的逐行岗位。公告明确应往届毕业生，附件列 2027 年计划；黄金洞矿业为湖南黄金股份有限公司所属企业。本来源仅覆盖该子公司该公告，不声称覆盖上市公司其他单位。
- 不把正文的专业方向当作另一个岗位目录，不采集后续操作工社招，也不按招聘人数扩行。公司地址不直接冒充每个岗位的工作地点，未给出的岗位职责和截止日期留空。

## 输入输出与失败行为

- 输入为湖南人才网带原始公告 ID 的公开 HTML 和唯一 XLSX 附件；输出附件岗位行中的名称、学历和专业要求，保留公告发布时间与附件证据。当前附件有连续编号 1–17 共 17 岗。
- 公告主体、届别、应届范围、附件链接或 XLSX 表头/连续序号不符，或下载/解析失败时，报告失败而非空结果。缺少导入字段进入待补全。

## 可验证验收条件

1. 离线测试覆盖公告附件身份、连续岗位编号、表头及新增/缺失行的失败边界。
2. Crawl4AI 实采 coverage complete、selected>0，单源只读审计通过后启用正式绑定。
