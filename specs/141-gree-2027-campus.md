# SPEC-141 格力电器官方校招目录

## 目标

接入名录 COM0152 珠海格力电器股份有限公司的官方 `https://zhaopin.greeyun.com/home`。2026-10-15 探测到公开 `property=1` 校招目录 53 条、每页 8 条，列表和详情均有岗位代码、名称、职责、资格、地点、学历和发布日期。穷尽所有页并逐条关联详情，只输出仍展示的正式校招岗位。

## 非目标

不采社会招聘或校园大使活动；不从面试城市推断工作地点；不虚构未公开的截止日期、详细地址或分类。

## 输入、输出与失败行为

输入为官方页面观察到的 `/api/apply/jobs?category=&pageNum=1&pageSize=8&property=1`，按同样无筛选条件遍历后续页，并通过 `/api/apply/job/details?jobCode=...` 校验岗位详情。输出公共快照、岗位信息表、严格导入表、待补全及证据。页间总数须稳定，岗位 Code 唯一，页数与总数闭合，末页明确到达；详情 Code、职位名及公开状态须与列表一致。分页或协议变化停止并记录覆盖问题；单条详情失败隔离，已有成功岗位与证据保留。

## 可验证验收

1. 离线回放覆盖分页、重复 Code、详情错配和局部详情失败。
2. 实站全量 `expected=listed=unique`、详情数量闭合、`coverage=complete`，且正式岗位数大于零。
3. 通过 Ruff、ty、pytest 与真实采集验收，更新本批进度和可复现入口。
