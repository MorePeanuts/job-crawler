# SPEC-275 2026 独角兽榜单招聘入口调查

状态：2026-10-21 首轮检索完成；本阶段只扩充待获取来源并调查官方招聘入口，不接入适配器或采集岗位。

## 目标与非目标

从用户指定的[《中国独角兽排行榜2026》](https://baijiahao.baidu.com/s?id=1867291820103836789&wfr=spider&for=pc)附录提取企业显示名，和 `sites/sources.csv` 去重，加入待获取清单，逐家寻找企业官方招聘入口或企业官网明确指向的招聘平台。榜单名可能是品牌、产品或集团简称，不在没有证据时当作法定主体名称。已有来源不得重复创建。此阶段不开发或启用适配器，不从高校就业网、招聘聚合站复制入口，不把链接存在视为校招岗位已覆盖。

## 输入输出

- 输入：该文章附录图片、当前 `sites/sources.csv`、企业官网及招聘页的公开证据。
- 输出：追加到 `sites/sources.csv` 的候选来源，`招聘官网` 仅存经官方页面核实的入口；备注标注榜单简称、主体待核实、来源和本次核验状态。逐家调查台账见 `docs/unicorn-2026-recruitment-research.md`。
- 原附录图片为八页，逐行识别到 309 条；“光轮智能”在原榜单出现两次，去重后 308 个显示名。原清单的 `COM0285` 已有“超聚变数字技术股份有限公司”，因此本次新增 307 个候选来源。文章叙述的 310 家与可见附录条数不一致，暂不虚构缺失条目。显示名中“PingCAP／平凯星辰”“帕西尼感知科技／帕西尼”疑似同主体，保留待核实，不把 307 个来源宣称为 307 家不同法人。

## 失败行为

无法证明官网归属、链接仅来自第三方招聘平台搜索结果、入口失效、存在不同法人的同名企业、或目前找不到招聘页时，保留空 URL 与待核实状态；不推测常见域名，不将无结果等同于企业没有招聘站。来源 ID 稳定；后续核实法定主体时更新名称并保留榜单别名与证据。对文章 OCR 疑点先人工对照图片再录入。

## 可验证验收条件

1. 榜单条目、去重、旧来源匹配和新增来源数量守恒；新增来源 ID 唯一，不改变原 500 家记录或已有绑定。
2. 新增来源均可追溯到榜单显示名；暂用简称的备注明确“主体待核实”。
3. 每个填入的招聘 URL 有可访问的企业官方招聘页，或有企业官网明确指向它的证据；未核实者留空。
4. `sources list` 可读新清单，所有新增来源仍为 pending/missing，无新增 ready 绑定。
5. 完成质量门禁；调查结果和未完成范围明确记录，不把本阶段称作适配器接入。首轮逐名检索若未找到可靠入口，保持空 URL，并标记为待复核。

## 需求与验证

- 榜单完整性与去重：逐页识别台账、来源数量/唯一性核对。
- 链接可信度：逐个官方页面记录；待核实保持空值。
- 运行安全边界：现有来源解析与状态测试、完整项目质量门禁。
