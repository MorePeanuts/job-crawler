# SPEC-178 国泰海通官方校园目录

状态：开发中；SPEC-156 B 组 COM0199。

## 目标与非目标

官网 hr.gtht.com 为合并后的国泰海通证券股份有限公司，校园入口 `/recruitment/main/recruit2`。完整遍历全部公司/部门，不只总部或首屏30条；不登录、不触发“立即申请”、不提交简历。首页独立实习目录不纳入。

## 输入输出

校园页公开 systemjobtype="2,4"、公司筛选为空；脚本 getJobList 对 filterUrl() 当前校园路径 POST n=1、company[]=空、systemjobtype=2,4、p=页码，返回 HTML 列表片段。dataTotal=114、pageSize=30、current=1，本轮四页。

每 `.job-list-con > ul` 是一条岗位，`a[data-job_id]` 为源 ID，依序标题/实际招聘机构/学历/人数/地点；隐藏 `.job-description-li` 含完整职责要求，同页提取而非投递后读取。使用公共段落拆分器保留正文，未公开的发布日期和截止保持空；不将历史宣传图的春招截止移用到当前秋招岗位。

## 失败行为与验收

类别或公司筛选变化、分页计数不一致、ID重复、卡片字段位置或正文缺失、请求回登录页均明确失败；已成功页保留。回放覆盖完整分页、隐藏详情、重复/提前空页与总数变化；正常 UI 第二页交互核对、完整实采、公共分类补全及只读审计通过后启用。
