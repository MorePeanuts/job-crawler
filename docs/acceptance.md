更早的详情实现曾读取建行部分详情，确认 NHR107 及子单位参数关联；后来停止该次未完成运行，改为上述完整目录与过期预筛选验收。该早期运行不作为全量完成依据。

两个真实输出 `jobs.xlsx` 均为空导入表，是筛选和模板校验的结果。平安原始岗位保存在 `outputs/production-live-retry/jobs.json`，待补全原因在 `review.json`。配置后台分类树、地点和学历规则后，可用 `job-crawler export` 重新导出；重新导出不重新确认岗位开放状态。

## 模型验收

使用环境变量中的密钥，真实调用 `deepseek-flash` 测试固定用例“最低学历要求：本科及以上。”。结果为“本科”，保留有效原文引证；最后一次验证限制为一次调用，审计在 `outputs/llm-smoke-final/`。这是模型 SDK 冒烟测试，不是采集到的真实岗位。

默认关闭思考模式，支持独立 `extra_body` 覆盖。已兼容模型用全空字段对象表示缺失值。非空值没有引证、分类不在配置树、输出截断时仍拒绝采用。自定义模型名/端点/环境变量配置通过模拟客户端测试；未对所有兼容服务逐一实测。

## 当前限制

1. 四站适配器与回放已实现，但中石油、阿里当前环境的实时完整性仍受阻；需要在可访问环境复验，不能标记为全站实时验收通过。
2. 分类树按用户要求独立配置，尚未获得真实后台父子关系。地点与非标准学历也需明确映射，不进行猜测。没有连接用户导入后台，未执行真实整表导入。
3. 本轮只实现公开校招目录，不含登录会话导入、验证码处理、扫描附件 OCR、其他 224 个链接适配、定时调度或分布式执行。
4. 恢复重取目录并复用同运行的成功详情，保留采集时间；招聘网站不是事务快照，不承诺跨分钟绝对一致。原运行超过恢复时限或代码/配置变化时必须新建任务。

以上限制均在 README、配置及运行状态中可见，不以离线测试通过替代真实访问结果。
