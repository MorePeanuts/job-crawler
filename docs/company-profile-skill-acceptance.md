## 场景走查

以下为指南的人工路径审查，不等于重新联网完成这些公司研究或导入系统验证。

| 场景 | 对应执行路径与失败处理 |
| --- | --- |
| 仅指定新一批岗位表 | 固定附件与信息表集合，按工作类型计算校招记录；不带入历史企业，不写死 50 家 |
| 明确合并旧公司表 | 核实主体身份后取并集，保留旧字段和 Logo；重叠计数用指定最新快照或稳定键去重，不能直接累加 |
| 名录含零岗位/失败企业 | 区分表中企业与名录范围，解释家数差异；有证据的零与未知失败分别处理，不能为凑家数虚构记录 |
| 子公司/集团或注册地/总部冲突 | 先核实本行主体与地址用途，记录来源期间；未明确的门牌、人数和归属留待补全 |
| 缺少可靠透明 Logo | 寻找清晰官方素材并保留比例；白标/彩色底块记录例外，无法取得时报告缺口，不生成仿冒标识 |

## 验收边界

本次新增的是随项目分发的操作指南与模板，没有新建公司爬取/导出 CLI，也没有执行新的公司联网研究、Logo 转换、成品渲染或系统上传。因此上述检查不构成某一批公司表的真实性或可导入保证。每次实际执行仍须查证最新公开资料，并按 skill 的程序与视觉清单验收。客户端若尚未发现本地 skill，可直接读取 SKILL.md 执行。
