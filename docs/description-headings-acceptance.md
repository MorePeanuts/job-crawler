# 岗位正文章节修复验收（SPEC-034）

日期：2026-10-13。范围：2026-10-12 汇总快照与保存的源站响应；未重新抓取网站或调用模型。

## 原因与修复

智联和前程无忧旧解析按标题词切分，遗留标题两侧括号，并可能把普通句子里的“岗位要求”误切掉；Moka 旧解析只识别整行标题，遗漏同行、跨 HTML 段、混排英文、不可见字符等形态。其他独立字段也存在未删除的章节标题。

共享解析器完整消费明确标题、编号与括号，支持逆序及重复章节、同义词、“如下”标题、源站漏掉一个括号的独立标题行；保留正文中的普通括号、词语和标题引用。职责与要求已分开的字段仅去除行首标题，不根据源站误写的标签移动内容。前程无忧继续忽略首个章节前的目录元数据。其他适配器保持原有无标题回退。

接入智联、Moka、前程无忧（含 COAPI）、Hotjob、哔哩哔哩；公共岗位构造和导出规范化同步清理独立字段。原始快照不会在普通导出中被覆盖；代码摘要变化使未来采集不复用旧解析实现的增量详情。

- 只修改有正文变化的岗位，忽略纯空白重排；历史学历、分类、地点、日期、采集时间、导入范围均未重算。正文字段重新拆分可能恢复此前漏识别的要求段，或还原旧逻辑误切掉的词语。
- 值由程序生成；在原工作簿副本中替换目标单元格文本。其余 14 个 ZIP 部件字节一致；首表除目标单元格的文本和必要字符串存储类型外，XML 保持一致，样式、行高、列宽、筛选、链接及验证规则保留。
- 另外用独立工作簿读取器逐行逐列核对：仅 I/J 发生变化；行数与四个工作表名称一致；职责末尾 `【` / 要求开头 `】` 残留为零，明确的 `【岗位职责】` 等标题残留为零。
- 已检查联通截图岗位、上海建工、阳光电源的修复前后渲染。长正文保持源表布局，完整内容保存在单元格中。
