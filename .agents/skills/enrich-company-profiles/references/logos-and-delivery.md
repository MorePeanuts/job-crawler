# Logo 头像与导出检查

## 官方素材到头像

1. 优先取企业官网品牌资源、官方页面 Logo、企业自己的招聘页资源；可检查页面实际引用的 img、SVG、CSS 背景及资源文件。保留确切 URL。招聘平台图标、浏览器通用图标、广告联名图不能替代企业 Logo；集团标识用于子公司时需要确认是其官方对外使用标识并说明。
2. 优先高分辨率透明 PNG，其次清晰的官方 SVG/其他图片。扩展名不是格式证明，检查实际格式、尺寸、alpha；32×32 favicon 放大通常不合格。拿不到清晰可靠素材就报告缺口，不生成仿冒 Logo，不从来源不明的图标库随意取图。
3. 查看原图后再用当前环境允许的图片工具处理，严格遵守该工具/技能约束。输出 512×512 RGBA PNG，等比例缩放并居中，至少留约 10% 边距；另核对圆形安全区。很长的字标优先找官方独立标记版本，不通过拉伸、挤压或删字强凑正方形。
4. 透明画布并不代表源图已去底。仅在能明确区分背景与标识时去除外部纯色背景，不全局删除白色/浅色像素而损伤 Logo 内部。品牌自身的彩色底块可保留并在外部留透明边距，不能宣称品牌底块已变透明。
5. 白色标识优先寻找官方彩色/深色版本；确实只有官方白色版时用小范围合适的对比底板保持可见，外围仍透明，并记录例外。无法安全去底时保留真实素材并说明，透明要求不能优先于真实性和清晰度。
6. 制作全部头像的联系表，含公司简称/稳定 ID；在浅色和深色背景查看透明效果，并用圆形蒙版预览最终头像。逐张排除空白、错公司、模糊、截断、白底残留和图片顺序错位。圆形预览用于检查，不必把交付 PNG 裁成圆形。

ZIP 只放最终 PNG，文件名采用稳定 ID 加公司简称，保证与表中企业一一对应；需要映射时加入简短清单。外部文件名必须清理路径分隔符，拒绝路径穿越。合并表要同时保留旧企业的已核实头像，不能漏图。

## 成品程序检查

- **范围**：有效公司行（按 C 非空识别，不能用工作表 max_row）与已确认名单集合完全一致、无示例和空名称、无非预期重复。单批不混入历史企业；合并后数量等于核实后的主体并集。
- **计数**：K 为文本，逐公司值及其总和与选定校招源记录一致；经过去重/换快照的合并按记录的规则复算。未知/失败计数单列，不能强行凑总数。
- **模板**：A–M 依次为 `图片,名称,公司全称,公司类别,类型,行业,规模,地点,公司简介,校招官网,校招招聘岗位总数,社招官网,信息来源链接`；N 为 `详细地址`。枚举及填写说明工作表保留，E/F/G 验证范围覆盖有效行。
- **字段**：E/F/G 非空值确在相应枚举；缺少模板必填信息的行明确标记待补全。链接是完整 http(s) URL 且匹配企业/租户；网页不可访问时记录限制，不把链接语法正确说成在线有效。
- **地址**：H 与 N 的省市区、公司主体和总部口径一致，有详细依据；部分地址或仅注册地址的例外有批注和报告。不得依据招聘城市推定总部。
- **图片**：每家公司一张 A 列图片对象且锚点行匹配。所有交付头像是可解码的 512×512 RGBA PNG，检查 alpha 确有透明像素及图形未消失；实际不透明例外必须明确列出，不以 RGBA 模式冒充透明。嵌入缩放比例正确、边界在所在行内。
- **安全与可读性**：外部文本按字符串保存，没有意外公式或 Excel 错误值；长文本换行，数值不变科学计数法，文件无损重开。原模板和输入岗位表没有被改写，输出路径不覆盖历史文件。

至少渲染或打开首行、中间、末行，以及最长简介、最长地址和全部待补全行；检查图片不遮字、行高列宽合适。若当前工具无法渲染，使用可用应用检查；仍无法视觉检查就明确记录限制，不能把 XML/结构检查称为视觉验收。

最终 XLSX 保留来源链接，关键缺失可用醒目填色及单元格批注提示，研究过程留在独立报告，不添加导入系统不认识的辅助列或研究工作表。交付“文件已生成”“已通过离线检查”“已在系统成功导入”是不同结论，只报告实际完成的层级。
